# Deploy Velora Salon on Render

## 1. Push the project to GitHub

From the project folder:

```powershell
git init
git add .
git commit -m "Prepare Velora salon for Render"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

Do not commit `.venv/credentials.json` or any Gmail password.

## 2. Create the Render service

1. Open Render and choose **New + -> Blueprint**.
2. Select the GitHub repository.
3. Render reads `render.yaml` and creates the web service.
4. Deploy the service.

The service runs with Gunicorn using `.venv/app.py`.

## 3. Add required environment variables

In Render, open the service's **Environment** page and set:

- `GOOGLE_CREDENTIALS_JSON`: paste the complete contents of `credentials.json` as one JSON value.
- `SMTP_PASSWORD`: a Gmail App Password for `valorasalon@gmail.com`.

`FLASK_SECRET_KEY` is generated by `render.yaml`. `SMTP_USERNAME` and `OWNER_EMAIL` are already set to `valorasalon@gmail.com`.

## 4. Google Sheet access

Share the configured Google Sheet with the service-account email from `credentials.json` and give it Editor access.

After deployment, Render provides a public URL such as:

`https://velora-salon.onrender.com`
